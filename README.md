# skillai-komprestoken

Skill AI untuk jawaban ringkas -- mempertahankan detail teknis, kode, dan pesan error.

## Untuk apa
Menghemat token output dengan memangkas gaya bahasa, bukan mengubah isi teknis.

## Isi repo
- `skills/kompres-token-claude/` -- untuk Claude Desktop
- `.agents/skills/kompres-token-opencode/` -- untuk OpenCode
- `.claude-plugin/` -- manifest plugin Claude

## Cara pakai OpenCode
Buka repo ini sebagai project, lalu minta agent: "pakai skill kompres-token".

## Cara pakai Claude Desktop
Customize -> Plugins -> Add marketplace -> masukkan `rexygilang/skillai-komprestoken`.
